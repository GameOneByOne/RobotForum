# Robot Developer Platform

> 机器人开发者的成长地图

## 00 - Product Overview

Version: v1.0

------------------------------------------------------------------------

# 1. Product Vision

Robot Developer
Platform（RDP）不是一个传统论坛，而是一个面向机器人开发者成长过程设计的平台。

核心目标：

> 帮助每一个机器人开发者，从零开始，最终独立完成属于自己的机器人项目。

平台围绕：

-   学习机器人开发
-   沉淀工程知识
-   解决开发问题
-   分享实践经验
-   完成机器人项目

建立完整成长闭环。

------------------------------------------------------------------------

# 2. Product Position

一句话定位：

> 机器人开发者的成长地图。

它不是：

-   普通论坛
-   博客平台
-   Wiki
-   Github

而是连接：

学习、知识、讨论、项目和资源的机器人开发生态。

------------------------------------------------------------------------

# 3. Core Principles

## Learning First

所有功能首先考虑：

是否帮助开发者成长。

------------------------------------------------------------------------

## Knowledge First

讨论不是终点。

信息流转：

Question

↓

Discussion

↓

Best Practice

↓

Knowledge

------------------------------------------------------------------------

## Project Driven

学习最终需要落到实践。

成长路径：

Learn

↓

Build

↓

Share

↓

Grow

------------------------------------------------------------------------

## Minimalism

拒绝：

-   娱乐化设计
-   无意义社交机制
-   复杂等级体系
-   流量导向设计

强调：

Content First。

------------------------------------------------------------------------

## Engineering Mindset

网站本身采用工程化设计：

-   可维护
-   可扩展
-   高一致性
-   长期演进

------------------------------------------------------------------------
