# 知识库 Markdown 阅读规范

正文默认 17px，读者可选择 15 / 17 / 19px。深浅色和字号保存在浏览器中，仅影响阅读区域。

## 图片

继续支持 `![说明|宽度百分比|block/left/right](图片地址)`，例如：

```markdown
![软件包安装关系|80|block](https://example.com/packages.gif)
```

图片自动显示说明，点击打开可用 Escape 关闭的放大预览。GIF 可以暂停到当前帧或继续播放；重播使用新的图片资源实例，跨域来源禁止读取时会显示提示。移动端左右浮动图恢复为独占一行。小图保持原始尺寸，避免放大失真。

## 代码

使用语言标记；可加 `title="文件名或命令说明"`。终端命令使用 bash，纯输出使用 output 或 text。复制按钮复制完整原文，包括折叠部分，不包含行号。代码默认横向滚动，可主动开启换行。超过 16 行时提供展开按钮。

```markdown
```python title="distance.py"
print(1.2)
```
```

原有 `:::code-tabs` 多文件语法保持兼容。

## 说明块

普通引用仍按 Markdown 显示。以这些标记开头的引用会获得专门样式：

```markdown
> [!CONCEPT]
> 概念解释。

> [!EXAMPLE]
> 具体例子。

> [!MISCONCEPTION]
> 常见误解。
```

也支持 NOTE、TIP、WARNING。

## 表格

表格采用行分隔与交替底色。数字列可用 `---:` 右对齐，单位放在表头；宽表格在自身容器内横向滚动。

## 公式

行内使用双美元号，例如 `$$x^2$$`。独立公式把两个 `$$` 各放一行，支持 LaTeX 分式、矩阵和上下标。单美元号不作为公式，避免普通价格或终端表达式被误解释。代码围栏 math 也支持公式展示。渲染前保留 HTML 清理，公式不启用可信 HTML 命令。

## 目录与翻页

标题自动生成段内目录，代码示例与独立公式不参与目录。重复标题有独立锚点。章节底部提供上一章和下一章，窄屏默认折叠章节导航。

## 沉浸式阅读

阅读工具栏的“沉浸式阅读”按钮优先使用浏览器 Fullscreen API；不支持或被拒绝时使用铺满视窗的布局。隐藏网站导航、页脚和其他页面内容，正文居中，工具栏随阅读滚动保持可见。可继续切换字号、明暗主题、章节导航和上一章/下一章。图片放大框在原生全屏元素内打开。

通过退出按钮、Esc 或浏览器退出全屏操作恢复普通阅读，保留当前章节和主题，并恢复进入前的页面位置。视窗模式锁定背景滚动和键盘焦点；退出或离开阅读页时恢复这些状态。

## 本地预览

`npm run dev -- --port 3001` 后打开 `http://localhost:3001/reading-preview`。预览页复用正式阅读组件，包含已发布 Linux 内容与格式示例；生产环境该预览路由返回 404。
