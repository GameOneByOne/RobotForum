## 内容维护

编辑器提供学习等级和学习顺序。等级写入 knowledge.difficulty，并同步中文等级标签；顺序通过现有标签关系保存为 `学习顺序01` 等标签，无需新增数据库字段。页面读取既有中文等级标签以兼容旧编辑器已发布的课程，未标记时使用数据库 difficulty。卡片不显示内部顺序标签。

等级内先按学习顺序升序排列，未设置顺序的文章排在最后作为拓展阅读；同序号使用标题和 slug 保持稳定顺序。筛选与课程名称、简介、标签搜索可同时使用。正文全文搜索仍由站点全局搜索提供。

已有六篇文章的正文和章节结构保留，仅更新分类标签；ROS 2 的占位简介已替换。新增九篇文章各含三个子章节。
